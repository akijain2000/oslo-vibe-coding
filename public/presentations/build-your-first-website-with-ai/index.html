Oslo Vibe Coding
Part 2 / Build

Our first build prompt

Describe the website, not every line of code
Build a one-page website called Oslo Hack.
It helps people in Oslo find others to build small projects with.
Use photo.jpg. Colors: #110F17, #FBF7F0, #FF5A2C.
Include navigation, a headline, an intro, Meet / Build / Share, and a footer.
Add a button that shows and hides a short session plan.
Use index.html, style.css, script.js, and photo.jpg. No libraries.
Make it work on a phone. Do not add login, payments, or a database.
First explain your plan and ask about missing information.
After agreeing on the plan: "Go ahead. Build it and tell me how to preview it."

Part 2 / Add a skill

Skills: reusable recipes for your agent

The job

Review this website before publishing.

The checks

Phone layout, keyboard access, working links, and clear button labels.

The output

Issues, fixes, and retest results.

Example review recipe / instruction body
# Website review
1. Open desktop and phone layouts.
2. Check images, links, and buttons.
3. Test Tab and Enter navigation.
4. Describe issues with evidence.
5. Fix agreed issues, then retest.
6. Ask before publishing.
