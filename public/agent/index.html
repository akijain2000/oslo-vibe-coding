Oslo Vibe Coding · Session 07

Build your first agent, for free.

A Telegram assistant for Oslo that answers, checks live departures and weather, remembers you, and messages you first. Runs on Val.town's free plan with its built-in model. No API key, no card.

Read the ten setup steps

The six files

Create a Val.town project called oslo-assistant and paste each of these in as a file with the same name.

  • agent.tsThe loop. Ask the model, run the tool it asks for, feed the result back, stop when it answers or the budget is spent.
  • tools.tsLayer 2. Entur departures and Yr weather, keyless Oslo open data.
  • memory.tsLayer 3. SQLite tables for messages, notes and reminders, plus the remember, recall and set_reminder tools.
  • model.tsLayer 1. Val.town's built-in model by default; set OPENROUTER_API_KEY to switch to OpenRouter's free models.
  • telegram.tsHTTP trigger. Telegram posts each message here; one request is one turn of the agent.
  • reminders.tsLayer 4. Cron trigger, every 15 minutes. Sends reminders that are due.

Also here

  • agent.test.ts, three tests for the loop. Run with node --test agent.test.ts.
