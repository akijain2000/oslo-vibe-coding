Build prompt

Build a one-page website called Oslo Hack.
It helps people in Oslo find others to build small projects with.
Use photo.jpg. Colors: #110F17, #FBF7F0, #FF5A2C.
Include navigation, a headline, an intro, Meet / Build / Share, and a footer.
Add a button that shows and hides a short session plan.
Use index.html, style.css, script.js, and photo.jpg. No libraries.
Make it work on a phone. Do not add login, payments, or a database.
First explain your plan and ask about missing information.

After reviewing the plan: Go ahead. Build it and tell me how to preview it.

Check before publishing

  • The purpose is clear from the headline.
  • The photo and styles load.
  • The plan opens and closes.
  • The page fits a phone without sideways scrolling.
  • Links and keyboard navigation work.
  • No passwords, secret keys, or private information are included.

Publish on Vercel through GitHub

  1. Create a GitHub repository named oslo-hack.
  2. Unzip the project. Add index.html, style.css, script.js, and photo.jpg at the repository root, not the ZIP itself. Commit the files.
  3. In Vercel, choose New Project, connect GitHub, and import the repository.
  4. For this plain-file example: use Framework Preset Other, override Build Command with an empty value, and set Output Directory to . (project root). A generated framework app needs its own detected framework settings instead.
  5. Choose Deploy and open the deployment URL.
  6. Test it in a private window and on a phone. If access is restricted, review deployment protection before sharing it publicly.
