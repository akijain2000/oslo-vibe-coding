# Website Review

Use this reusable instruction with your AI coding tool. It is a checklist, not an installed agent skill; skill packaging and installation depend on the tool.

Review this website before publishing:

1. Open desktop and phone layouts. Check that no text is cut off and no horizontal scrolling is needed.
2. Check that images and styles load, links reach the intended destinations, and buttons do what their labels promise.
3. Test keyboard navigation with Tab, Enter, and Space. Confirm focus is visible.
4. Describe each issue with its location, expected behavior, actual behavior, and evidence.
5. Propose a focused fix. Make agreed changes, then repeat the relevant checks.
6. Report what you tested and anything you could not test. Ask before publishing.

Keep working features and the existing design unchanged unless a fix requires a change. Do not upload passwords, secret keys, or unrelated personal files.
